Sky-Sprint
"Sky Sprint" is an exhilarating and visually captivating game designed for players of all ages, offering a fun-filled adventure through stunning sky-themed environments. Players take control of Masked man, a spirited and agile character, who leaps and dashes through an ever-expanding world of landscapes. The game features straightforward, intuitive controls, making it accessible for children while providing enough excitement to engage adult players. Currently, "Sky Sprint" offers a basic yet enjoyable experience with its dynamic jumping and running mechanics. However, future updates will introduce a variety of levels and challenges, adding depth and new dimensions to the gameplay. With its bright graphics and engaging action, "Sky Sprint" promises endless fun and replayability. The addition of sound effects will further enhance the immersive experience, making every jump and sprint even more thrilling. Whether you're seeking a casual escape or an exciting challenge, "Sky Sprint" is set to become a delightful adventure for all.

## How it Works ?
 Player Movement: The player controls a character that can move around the game world. This is usually implemented with a node like KinematicBody2D and scripted movement logic. The character responds to player input and interacts with the environment using collision detection.
Tilemap Management: The game world is built using a tilemap, allowing you to design levels efficiently. The tilemap provides the ground and obstacles for the player and other game elements to interact with.
Collision Detection: Both the player and environment use collision shapes to ensure realistic interactions—preventing the player from walking through walls or falling off platforms.
Object Spawning: Enemies or obstacles can be spawned at random or fixed intervals, creating challenges for the player. The player must avoid or interact with these elements to progress or survive.

## How to configure
1. Download and Extract Godot
       Go to the official Godot website and download the latest version for your operating system. Extract the downloaded ZIP file to your preferred location. Godot does not require installation; simply extract and run the executable file (e.g., Godot_v4.4.1.exe).
2. Launch Godot
       Double-click the Godot executable to open the Project Manager. The Project Manager allows you to create new projects or open existing ones.
3. Create a New Project
   Click the “New Project” button in the Project Manager. Choose a project name and select a folder where your project files will be stored. It’s recommended to use a dedicated folder for all your Godot projects. Select the renderer (the default “Forward+” is recommended).Click “Create & Edit” to open your new project in the Godot Editor.
4. Start Developing
        In the Godot Editor, you can: Navigate the interface and use core editing tools, Add 2D nodes, import assets, and start scripting with GDScript or C#. Save your scenes and scripts within the project folder.
5. (Optional) .NET/C# Support
        If you want to use C#, download the Godot version with .NET support and install the .NET SDK (version 6 or higher). You can also use an IDE like JetBrains Rider, which has a Godot plugin for enhanced C# development.
